# 企业情报与差距弥补（company-intel.md）

Stage 0 · 企业匹配分析的工作手册：联网采集企业情报 → 画理想候选人画像 → 用人者视角 gap 分析 → 弥补方案。全程遵守 R8 双库隔离（企业库 ≠ 个人库）。

## 0. 双库隔离纪律（R8 展开）

| | 企业库 company store | 个人库 candidate store |
|---|---|---|
| 内容 | 目标公司公开信息：官网、招聘 JD、技术博客、GitHub、新闻/融资、产品观察 | 用户简历、项目材料、对练记录、评分证据链 |
| 性质 | 外部公开数据，可聚合缓存 | 敏感个人数据 |
| 允许 | 跨公司聚合、脱敏后引用 | 仅本用户会话内使用 |
| 禁止 | **写入任何个人数据**（简历句子、姓名、评分） | **写入任何企业情报**（避免污染个人证据链；引用企业情报只许以「情报卡编号+摘要」形式标注） |
| 存储 | `company-intel/` 域 | `candidate-materials/` 域 |

gap 分析是两库的**只读 join**：每条 gap 的证据必须 `[C-xx 企业库情报]` 与 `[P-xx 个人库原话]` 成对出现（同一表格行分列，或以 vs 连接），join 结果落在报告层，不回写任何一库。任何「把简历投进企业库做向量检索」或「把企业情报存进个人档案」的做法都是违规。

## 0.5 候选人论文素材 [T-xx]（补丁 v1.5——个人库一等公民）

有论文的候选人（含在投），论文入库为最高证据等级个人素材，存 `candidate-materials/papers/`。

- **入库字段**：标题 / 作者位次 / 年份 / 会场（在投标 in review + 目标会场）/ arXiv 号或 DOI / 一句人话贡献 / 与目标岗位的关联 / 可引用量化结果。
- **真实性核验（防 V1 注水）**：arXiv / DOI / Google Scholar / ORCID 任一可查且作者名与简历一致才标「已核实」；查不到标「未核实」，材料攻防中作为攻击点。
- **证据等级（取数优先级）**：已发表 [T-xx]（同行评审）＞ 在投 [T-xx*]（标审稿状态）＞ 简历自述 [P-xx] ＞ 口头自述——预演答案、话术、简历重塑补量化一律从高等级取。
- **R8 边界**：「候选人↔论文」的关联属个人库敏感信息，禁止写入企业库/行业卡。

## 1. 企业情报采集清单（联网）

按优先级抓取（抓不到的项标注「未获取」，禁止编造）：

1. **目标 JD 原文**（招聘官网/BOSS/拉勾/LinkedIn）：显性要求（技能/年限/学历）+ 隐性信号（反复出现的词、排序靠前的要求、加分项=真实痛点）。
2. **技术栈证据**：公司技术博客、工程团队 GitHub、大会分享、JD 里的自研系统名——推断语言/框架/中间件/规模。
3. **业务与阶段**：主营业务、toC/toB、用户量级、融资/上市状态、近一年重大动向（新业务线=大量招人=容错高；收缩期=门槛高）。
4. **工程文化信号**：JD 措辞（「抗压/大小周」vs「工程卓越」）、开源活跃度、面试流程描述（几轮、有无算法/系统设计轮）。
5. **该公司的「考法」**：面经（牛客/脉脉）中高频题与挂人点——直接决定对练题定制。

每条情报落卡格式：`[C-01] 来源+日期+原文摘要 + 可信度（官方/二手/传闻）`。

**国际多语言调研纪律（全球调研库 · 补丁 v1.5）**：中文互联网资料只是起点，不是全部——
1. **多语言信源（英文必查，但不限于英文）**：每家目标公司至少核验一个英文源（英文官网/国际媒体/英文技术社区与论文）；其他语言存在优质一手内容也须纳入（日文：相机/光学/机器人产业一手报道；韩/德/法文：当地市场与竞品动态）。判断标准是「一手与权威」，不是语言本身——公司母语官网、当地监管文件、当地行业媒体优先于任何语言的转述。
2. **国内 + 国际竞品都要比**：只看国内会低估国际水平线，只看国际会误判本土化壁垒。
3. **调研四类并行（不止财经）**：技术（论文/技术博客/开源仓库）、产品（官网/发布会/第三方评测）、市场（行业媒体/竞品动向/人才流向）、财经（上市公司查财报关键数字——营收/增速/毛利率/研发占比，标财报期；未上市查融资轮次/估值/投资方）；市场规模数据必须标来源与年份，单一商业数据库估计注明「单一来源，参考性」。
4. **先进水平判断**：「谁在赢」的结论须有国际会议/国际产品证据支撑，不许只凭国内媒体报道下结论。

## 1.5 行业全景采集（竞品 + 学术，注入面试官知识库）

目标公司之外再抓两类公开信息，落企业库子域 `company-intel/行业全景/`：

1. **竞品研究（2~4 家）**：直接竞品的打法对比（产品形态/技术路线/公开的架构分享）、与目标公司的差异点——面试官问「竞品都在做 X，你怎么看」的弹药。**国内与国际竞品各至少一家**（理由见上节纪律 2）。
2. **学术研究梳理（5~10 篇）**：该公司业务方向相关的近年论文/顶会工作（推荐系统、内容审核、风控、存储……按业务定），摘要级梳理，逐条标来源+年份+可信度。
3. **行业趋势**：近 1-2 年行业公认的变化方向。

**五维分析框架（固定常量，所有行业同一把尺 · 补丁 v1.5）**：D1 产业链分层（硬件→数据→算法→平台→应用，标扩张/收缩）｜D2 价值流向（谁付钱、利润在哪层，用财经证据）｜D3 技术版图（路线派系之争，哪派在赢）｜D4 竞争格局（梯队+护城河类型）｜D5 学术谱系（顶会成果流向产业的速度与时差趋势）。行业级情报落 [I-xx] 卡（行业卡 [I-0x] / 公司坐标卡 [I-1x，company_ref→[C-xx] 唯一 join 桥] / 竞品矩阵 [I-2x：每家 2–4 家竞品，国内与国际各 ≥1 家] / 学术谱系 [I-3x] / 需求信号 [I-4x：跨公司 JD 关键词计数，只计数不复制原文]）。

**双线 Gap 分析（研究岗价值区）**：学术线（论文在争什么）× 工业线（产品在等什么）逐条对照 → 三类 gap：G1 学术热但工业未落地（卡点：成本/鲁棒性/数据）｜G2 工业痛但学术未解（最值钱）｜G3 落地时差（论文→产品周期及收敛趋势）。**双层输出**：报告层完整版（学术证据=论文名+编号，工业证据=产品/官方信息 → gap → 候选人机会）；话术层一句话——「学校在研究 __（论文），工厂在等 __（产品痛点），中间还没人打通——我的方向正好卡在这儿，一年内能落地。」话术每个空都从报告层取数，两边不许对不上。

**论文三级降级查证（不依赖本地库）**：① 本地库探测 ≤10 秒，空库直接跳过不阻塞；② 公开渠道主力：arXiv 原文 → OpenReview（投会版）→ Semantic Scholar（标题/年份/引用数判冷热）；③ 只剩博客/新闻解读 = 二手信息，只能作背景，禁止进面试话术。每篇三件套：编号（arXiv 号/DOI）+ 一句人话贡献 + 跟候选人的关系；**两个独立来源对上才算「查到」**（防记错防编造）；每批 ≤3 篇防搜索卡死。

**三层下钻答题骨架**（行业题评分锚点）：行业层（哪个环节在扩张）→ 公司层（坐标+护城河）→ 岗位层（价值链哪一环），三层各一句，每层挂 [I-xx]/[C-xx] 出处。

纪律：全部为公开外部数据（R8 企业库）；>3 个月的动向类信息用前刷新；传闻级信息标注可信度且**不进题面**；抓不到标「未获取」。

**行业题模板**（挂 K 业务理解 / L 权衡维度，启用时该两维权重临时上调）：
- 「你们行业竞品都在做 X，你觉得为什么？你们公司该不该跟？」
- 「这篇论文（行业卡 [C-xx]）的思路，放到你们的业务里用得上吗？代价是什么？」
- 「这个行业未来一年的最大变量是什么，对你们组的需求会有什么影响？」

## 2. 理想候选人画像（用人者视角）

站在该公司 hiring manager 立场（不是候选人立场）回答三个问题：
1. **这人来了头三个月干什么活？**（从 JD 职责反推：日常 60% 的工作内容）
2. **什么样的人我们会后悔没发 offer？**（技术深度？业务理解？稳定性？）
3. **什么样的人进来了我们会想换掉？**（过拟合的雷点：只会背题/无法独立排查/沟通成本高）

产出画像四维：硬技能基线（必须会）/ 项目经验形状（什么领域的什么角色）/ 软信号（文化关键词）/ 红线（他们的 V1–V5 等价物）。

## 3. Gap 分析（两库只读 join）

| Gap 编号 | 企业库证据 | 个人库证据 | 差距描述 | 级别 |
|---|---|---|---|---|
| G-01 | [C-xx JD 要求：熟悉 Kafka] | [P-xx 简历：无 MQ 经历，S8 自述「没用过」] | 消息队列实战空白 | P1 |

分级：P0 = JD 显性硬要求且简历零信号（不补大概率简历关都过不了）；P1 = 要求与信号存在明显落差；P2 = 表述/包装问题（能力在但没写到位）。
注意方向性：gap 分析找的是「企业要 vs 我有」，不是「我有多好」；同一条差距要写清是企业要求高还是简历没表达。

## 3.5 招聘官硬指标（Stage 0 量化产出，v1.4.0）

gap 报告固定附带三件：
1. **匹配度总分（100 分制）**：十维加权（rules-config dimension_weights，每维 0-10 × 权重 × 10）；分数必须带口径——每维扣分注明证据 [C-xx]/[P-xx]；重塑后复评同一口径，量化提升。
2. **Top5 缺失关键词**：JD 提取高频词/硬性词（出现 ≥2 次或任职要求前两条）vs 简历词表；每个标注「真实可对齐」（简历有相近经历可重述）/「需学习」（无素材走最快补法）。
3. **3 个第一眼减分项**（招聘官 10 秒视角）：量化模糊、年限/学历不符、声称过满（「精通」遍地）、频繁跳槽、排版混乱等——与 V1-V5 同源，作用于简历关。

## 3.6 反向岗位发现（D0，v1.4.0）——简历驱动找机会

1. **10 个搜索关键词，三桶提取**（禁取「负责/参与/熟悉」类废词）：硬技能词 / 业务域词 / 规模信号词（如「日均 200 万」「千万级表」）；可复用简历解析 [P-xx]；
2. **5 个增值词**：岗位市场高频、简历缺失、且与现有技能相邻（最快补法可覆盖）——搜「已有词 × 增值词」命中踮脚够得着的岗位；
3. 组合搜索（技能词 × 业务域词）召回 → **匹配分排序**（关键词管召回、§3.5 匹配度管排序）→ Top10 岗位/公司候选 + 初判 gap（回流最快学习法）；
4. **R8 外发豁免（关键词级）**：搜索仅外发非身份性技能/领域词；禁止外发完整句子、公司名、项目细节、姓名；查询串落盘可审计；
5. 预期管理：平台（Boss 直聘/猎聘）无公开 API，召回可能不全或过时——定位「候选发现 + 初筛排序」，投递前用户须在平台核实。

## 4. 弥补方案（每条 P0/P1 双路输出）

**路线 A · 补法（学习路径）**——3 步以内、每步可验证、给时间盒：
```
G-01 补法（示例）：
第 1 步（周末 2 天）：本地起 Kafka，复刻 S8 工单系统的「补删动作进队列」场景，跑通生产-消费
第 2 步（1 周）：在个人项目里实现一个「削峰 + 重试 + 死信」完整链路，记录一次故意断电后的恢复
第 3 步（验证）：把该项目写进简历一行，能扛住 O 卡两层穿透（用本 Skill 对练自测）
```

**路线 B · 展示法（快学能力的面试呈现）**——不空口说「我学得快」，用**已有的学习曲线证据**演示：
- 找简历里一次「从不会到上线」的真实记录（S8 的转行经历、S3 的自学压测），拆出「接触→掌握→落地」的时间线和产出；
- 面试话术模板：「这个 gap 我清楚（能说清它为什么难）。我补它的路径是 X，参照我之前 Y 周搞定 Z 的先例。目前已走到第 N 步，卡点是……」——把 gap 从减分项转成「自我认知+学习力」的加分项；
- 红线：禁止编造学习进度；展示法只对 P1 有效，P0 必须真补。

## 4.5 双输入学习引擎（问答挂点 × 差距清单共同决定）

输入（双来源）：① 问答记录中的挂点（答错/被穿透/诚实兜底的话题）+ 反思卡；② Stage 0 差距清单（P0/P1）。

**优先级 = 挂点次数 × gap 级别 × 下游价值**（下游价值四档从高到低：直连营收 / 支撑核心指标 / 服务内部效率 / 无明确下游）。gap 是 P0 但一答即对的不学，两边都不沾的不学。每条挂点输出「最快学法」，六条规矩：

1. **从已会处搭桥**（最近发展区）：候选人哪里答对了就从哪里接，禁止从零开通用教程；
2. **目标收窄**：学完标准 = 原题重测 ≥7 分且大白话档通过，不追求系统性掌握；
3. **资源直指**：行业全景卡里那篇论文/竞品做法 + 预演手册兜底话术的升级路径；
4. **时间盒 + 验证点**：如「周末 2 小时 + 重测」；超时未达标自动降级为「换短板打」；
5. **数学降权**（候选人数学基础有限）：数学密集路线（理论推导/变分/随机微分类）默认降一档；必须学时「工程直觉先行」——先用实验现象与几何直观讲通，再补最小数学集；话术遇数学穿透一律兜底，禁止硬刚推导；
6. **反端到端**（跑通 ≠ 学会）：任何「跑通 demo/整条管线」只是第 1 步，验收升级为「跑通 + 拆解」——能指出管线中最关键的一个模块并讲清输入/输出/为什么存在；黑盒跑通讲不出内部模块 = 未学会（对齐 V4）。

跨场次聚合：按优先级公式生成《个人学习计划》，每条带重测验证（原题复测 ≥7 才算学完）。

## 5. 与对练的衔接（经预演流水线）

Stage 0 结束后，把 gap 清单注入对练配置：P0/P1 对应维度提高选题权重（selection-rules.md 的「否决覆盖」因子思路），企业情报中的高频考点（面经）优先进入题库定制——例如 G-01 存在时，对练必含一轮 G3 消息队列场景题，验证候选人按路线 A/B 准备后的真实水平。

## 6. 未获取与诚实纪律

- 抓不到的信息标「未获取」，不猜；二手信息（面经/新闻）标注可信度；
- 企业情报有时效（标注采集日期），超 3 个月的融资/动向类情报使用前应刷新；
- 本手册的一切联网采集仅限公开信息，不采集个人隐私（哪怕公开），不做绕过反爬的抓取。
