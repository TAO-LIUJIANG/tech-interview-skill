## 快速开始

```bash
# 复制到 skills 目录（ZCode: ~/.zcode/skills/；Claude Code: ~/.claude/skills/）

```

一句话开用：「帮我练练面试」「看看我这简历能不能扛住追问」「跑 Stage 0 分析我和某公司的差距」

## 它适合谁

- 简历能写但**面试说不出**的人——需要话术打磨和独立盲评；
- 想投多家公司、**不知道差距在哪**的人——需要行业地图和差距清单；
- **拿到了面试邀请，但对这家公司的业务不了解**的人——Stage 0 帮你把行业、公司、岗位三层捋清楚，面试前一晚也能补；
- **不知道自己的简历能投哪些公司**的人——D0 反向岗位发现：从简历出发，找出匹配的方向和公司；
- 怕背题翻车的人——这套系统专治堆术语（讲不清原理直接扣分）。

## 设计哲学

| 哲学 | 人话版 |
|---|---|
| **能力优先** | 不看会背多少名词，看能不能把事情做出来、讲明白。 |
| **反浮躁** | 任何概念都要能讲给外行听——讲不清就是不会，堆术语直接扣分。 |
| **人机协同** | 重要的判断（要不要淘汰）必须人来确认；跑分、查字数交给机器。 |
| **链路定位** | 讲项目别报菜名，先讲流水线：原料哪来、我做哪步、成品给谁、怎么算做得好。 |
| **双线对照** | 每个技术标注在学校线还是工厂线——中间那条沟（gap）就是你的价值。 |

> 总纲：**写给人看，交给机器查**——人负责把话说清楚，机器负责挑错（结构/字数/来源/内容/截图五查）。

## 本 Skill 的特点

| 特点 | 说明 |
|---|---|
| **证据链评分** | 每次打分必须**逐字引用你的原话**，说不出原话的评分无效 |
| **诚实红线** | 预演答案每句**要有简历依据**，编造的东西上场一定穿帮 |
| **学习闭环** | 挂点自动回流，按**挂点次数 × gap 级别 × 离钱远近**排学习优先级 |
| **输出受限** | 文档 ≤600 字五段式、对话 ≤150 字，**机器五查**验收 |

## 功能亮点

- **独立盲评**：评委只看问答对、不知来龙去脉，防自己人放水；
- **论文三级查**：本地库 10 秒探测 → arXiv/OpenReview 主力 → 只有二手解读的不许进话术；
- **多语言调研**：英文必查、日文等一手内容也查；技术、产品、市场、财经都查，硬数字以招股书、财报这类原始文件为准；
- **双库隔离**：企业公开资料与你的隐私永不互写，差距分析只做「隔窗比对」；
- **行业数据库**：五层产业链地图 + 国内国际竞品 + 学术×工业双线找沟。

## 好答案 vs 差答案（同一道题，独立盲评）

**题目：介绍你在投的论文项目**

❌ **7 分**：「我做 LiDAR-3DGS 重建，设计了跨模态编码模块，PSNR 提了 1.5dB，在 nuScenes 从零训练，还验证了跨域泛化。」
> 评委：技术都对，但停在「做了什么」——「怎么注入的、为什么有效」没讲，像在念摘要。

✅ **9 分**：「上游是车载众包数据——6 个环视相机加 32 线激光，只覆盖 1.4% 像素，这是输入约束。我把它转换成可微的 3D 场景表征：稀疏度量真值注入初始化和监督，解决欠约束漂移——为什么必须这层做：漂移发生在表征层，下游修不了。输出给地图更新和世界模型训练消费。反馈上，nuScenes 复现到与论文只差 0.08dB，说明精度可审计。」
> 评委：链路完整（上游约束→自身转换→层级理由→下游消费→可审计证据），还主动讲了失效边界。

差距的 2 分不在技术，在**结构**——这就是「链路定位」哲学教的事。

## FAQ

- **必须联网吗？** 行业分析需要；对练/材料攻防纯本地可跑。
- **我的简历数据会被上传吗？** 不会。你的材料只存在你自己电脑的 candidate-materials/ 目录里，和公开的企业资料是两个库，互不写入。
